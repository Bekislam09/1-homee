# Правила Smash City
1. Не переписывать работающие системы без причины; сохранять независимость симуляции от Phaser.
2. После каждого этапа запускать `npm test` и `npm run build`, UI дополнительно проверять в браузере.
3. Не оставлять неработающие кнопки и не имитировать реализованные механики.
4. Исправлять найденные ошибки и добавлять осмысленные регрессионные проверки.
5. Ограничивать число частиц и выделения памяти в кадре; переиспользовать текстуры и объекты.
6. Не добавлять лишние зависимости, настоящую 3D-физику, фальшивые SDK и рекламу.
7. Фиксировать стабильные этапы в Git. Не публиковать без запроса.
8. Использовать существующий checkout: облачная задача уже изолирована, worktree не нужен.
