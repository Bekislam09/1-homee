# Правила разработки
Сохраняйте рабочие механики. Разделяйте симуляцию, рендер и платформы. Проверяйте `npm test` и `npm run build` после каждого этапа; UI дополнительно в браузере. Избегайте выделения ресурсов в кадре, переиспользуйте геометрии и материалы, ограничивайте NPC, тени и DPR. Новый игровой функционал должен иметь осмысленные тесты. Не подменяйте SDK и рекламу фиктивным успехом. Не создавайте worktree: облачная задача уже изолирована.
