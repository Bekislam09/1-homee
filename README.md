# SMASH CITY — Разрушитель города

Первая версия изометрической 2.5D-аркады на **Phaser 3 + Vite + JavaScript ES Modules**. Маленький бульдозер сносит игрушечный город, зарабатывает монеты и очки. Three.js не входит в зависимости и сборку новой игры. Файлы предыдущей игры в `src/game` сохранены как история разработки и не подключены к entry point.

## Запуск

Требуется Node.js 22.12+ (проверено на 24.19) и npm.

```sh
cd /workspace/1-homee
npm ci --cache /tmp/loot-npm-cache
npm run dev -- --port 5173
```

Production:

```sh
npm run build
npm run preview -- --port 4173
```

Все изображения генерируются локально из векторных примитивов Canvas и загружаются в текстуры Phaser. Звук процедурный. Сервер, секреты, CDN и рекламные SDK не нужны.

## Как играть

Нажмите «Играть». Цель первой смены — **1 000 очков разрушения за 90 секунд**.

- WASD / стрелки: движение в направлениях экрана.
- Пробел: короткий мощный таран по направлению ковша. Перезарядка 2,2 секунды.
- На сенсорном экране: виртуальный джойстик слева и отдельная кнопка тарана справа; одновременные касания поддерживаются.
- Esc / кнопка паузы: остановить или продолжить. Потеря фокуса автоматически ставит игру на паузу.

На карте 14 зданий. Сарай выдерживает 1 таран (25 монет), киоск — 2 (60), дом — 3 (120). Обычное движение ковшом в здание постепенно наносит слабый урон. Целые здания блокируют проезд; после разрушения остаются проезжаемые обломки.

Комбо растёт до ×3, если между разрушениями прошло не более 7 секунд. Оно умножает очки, но **не постоянные монеты**. За уже снесённое здание повторной выплаты нет. Повтор восстанавливает карту, таймер и комбо; заработанные монеты остаются в кошельке. Монеты и настройки сохраняются в отдельном `smash-city-v1` localStorage. При запрете хранилища игра продолжает работать, показывая уведомление об отсутствии сохранения.

В настройках работают переключатели звука и дополнительных эффектов. Музыка не реализована, поэтому отсутствующего переключателя музыки нет. Звук начинается только после действия пользователя.

## Файлы

- `src/smash/simulation.js` — независимая 2D-симуляция и миссия.
- `art.js` — изометрическая проекция, город, 3 типа зданий со стадиями повреждения, 8 ракурсов бульдозера и анимационные кадры гусениц.
- `scene.js` — Phaser Scene, глубина, камера, пулы частиц и анимация разрушений.
- `main.js`, `style.css` — меню, HUD, результаты, адаптивный ввод и настройки.
- `audio.js`, `platform.js` — процедурный звук, локальный адаптер и сохранения.
- `i18n.js` — ключи игровых сообщений для будущего расширения локализации. Полностью поставляется только русский интерфейс; прочие тексты меню ещё потребуют перевода.
- `tests/smash.test.js`, `tests/platform.test.js`, `tests/browser/game.spec.js` — проверки новой игры.

См. `ARCHITECTURE.md`, `PLAN.md`, `AGENTS.md`.

## Проверки

```sh
npm test
npx playwright test
```

Playwright использует системный `/usr/bin/chromium`; путь можно изменить через `CHROMIUM_PATH`. Если Vite не запущен, тесты запускают его автоматически.

**21 модульный тест:** движение и нормализация диагонали, границы, коллизии без туннелирования, направление ковша, обычный/усиленный урон, перезарядка и короткие нажатия, все типы зданий, однократные выплаты, комбо, таймер, результат, повтор, сохранение и недоступное хранилище.

Два теста проходят непрерывные маршруты через обычный API ввода без телепортаций и прямого изменения прочности: победа с комбо, а также победа без комбо (1 060 очков за примерно 50,55 секунды симуляции).

**3 браузерных сценария Chromium:** настоящее нажатие пробела и движение с клавиатуры; разрушение и частицы; победа; поражение по таймеру; меню/помощь/настройки; пауза; повтор; сохранение после перезагрузки; реальные одновременные touch-события через CDP; портрет 390×844 и горизонтальный экран 844×390; изменение размера Canvas; постоянное число объектов и текстур после 5 повторов.

Для ускоренной проверки победы браузерный сценарий подаёт движения и нажатия в симуляцию через dev-only `/?test`, не меняя позиции, очки или прочность. Проверка поражения сокращает таймер. Это не 90-секундный ручной заезд. В production отдельно проверены запуск и разрушение первого сарая настоящим пробелом: начислено 25 монет, ошибок JavaScript нет; тестовый доступ отсутствует. Старые тесты предыдущей игры оставлены в репозитории, но не входят в `npm test` новой версии.

## Ограничения и часть 2

- Проверены браузерные разрешения и эмуляция касаний; физический смартфон не тестировался.
- 30/60 FPS на целевых устройствах и ноутбуке с 4 ГБ не измерены. Нельзя считать эти показатели достигнутыми по облачному Chromium.
- Фрагменты используют управляемую анимацию, а не физику зданий. Декор проезжаемый, границы и целые здания твёрдые.
- Постоянное число Phaser-объектов и текстур — ограниченная проверка ресурсов, не полный heap-профиль.
- Phaser образует крупный vendor-chunk (~1,48 МБ до gzip, ~340 КБ gzip); Vite предупреждает о размере, сборка завершается успешно.
- В части 2: ручной баланс, дополнительная карта/миссии, профилирование на слабых устройствах, полный перевод английского интерфейса и проверка долгих игровых сессий. Платформенные SDK, реклама и публикация — следующий отдельный этап; рекламных заглушек нет.
