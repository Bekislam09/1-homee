# SMASH CITY — Разрушитель города, часть 2

Продолжение существующей изометрической аркады на Phaser 3, Vite и JavaScript ES Modules. Две локации, три вида техники и четыре задания; движение и разрушения первой части сохранены. Все изображения и звуки создаются локально, без CDN, серверной части и SDK.

## Запуск и проверки

Node.js 22.12+ (проверено на 24.19) и npm.

```sh
cd /workspace/1-homee
npm ci --cache /tmp/loot-npm-cache
npm run dev -- --port 5173
```

```sh
npm test
npx playwright test
npm run build
npm run preview -- --port 4173
```

Playwright использует системный `/usr/bin/chromium`; другой путь задаётся через `CHROMIUM_PATH`. Если Vite не запущен, тесты запускают его автоматически. Production собирается в `dist`. Тестовый доступ `/?test` присутствует только в dev-сборке.

Управление: WASD / стрелки — движение по экрану, Space — способность; на телефоне джойстик и большая кнопка справа. Esc / пауза останавливают заезд. При потере фокуса игра ставится на паузу. Настройки звука и дополнительных эффектов работают; музыки и фиктивных рекламных кнопок нет.

## Гараж, районы и прогрессия


Проект расширен без замены Phaser, движения, управления и разрушений первой части.

## Техника и задания

В меню появились «Гараж» и «Уровни». Начальный бульдозер бесплатен; экскаватор стоит 300 монет, машина с шаром — 650. Покупка открывает и выбирает машину; повторная покупка не списывает средства. В гараже показаны особенность, цена, скорость и перезарядка.

| Техника | Способность | Перезарядка |
| --- | --- | --- |
| Бульдозер | Быстрый рывок и сквозной снос слабых объектов | 2,2 с |
| Экскаватор | Точечный удар на 115 единиц вперёд; урон в момент контакта через 0,40 с | 2,6 с |
| Разрушительный шар | Удар на 125 единиц вперёд в радиусе 100; контакт через 0,55 с | 3,5 с |

Прежние Space / сенсорная кнопка запускают особую способность выбранной машины. Направление фиксируется на время работы стрелы. Прозрачная область на земле показывает цель.

| Задание | Район | Цель | Время | Первый бонус |
| --- | --- | --- | --- | --- |
| 1. Начало разрушений | Солнечный квартал | 1 000 очков | 90 с | 150 |
| 2. Срочный снос | Солнечный квартал | 8 зданий | 100 с | 250 |
| 3. Большое обрушение | Индустриальный район | Цепь из 3 сооружений | 100 с | 350 |
| 4. Мастер разрушений | Индустриальный район | 2 400 очков | 120 с | 500 |

Задания открываются последовательно. Промышленный район доступен после второго. Все задания выполнимы стартовым бульдозером: покупка техники не является скрытым требованием.

В промышленном районе появились склады, кирпичные башни и контейнерные конструкции. Первая башня стоит рядом со складом и контейнерами: её падение по направлению +X запускает понятную цепь. Башня повреждает соседей после падения через 0,45 с, склад/контейнеры продолжают каскад через 0,20 с. Цепь ограничена шестью объектами; каждое здание обрабатывается один раз, обломки проезжаемы.

## Рекорды и экономика

За успешное задание выдаётся одна звезда; вторая и третья зависят от времени. Пороги видны в карточках: задания 1–4 дают 2/3 звезды при времени не более 65/35, 80/55, 70/45 и 90/60 секунд соответственно. Сохраняются лучшие очки, комбо, длина цепи, время, звёзды и количество побед.

За разрушения выдаются монеты, а за победу — отдельный бонус. Первое прохождение даёт полный бонус; повтор даёт 45% монет за здания и 25% бонуса. Комбо и цепи увеличивают очки, не валюту. Первой победы с тремя зданиями достаточно для экскаватора (205 + 150 = 355 монет).

## Сохранения версии 2

`smash-city-v2` хранит баланс, технику, выбранную машину, открытые районы, завершённые миссии, рекорды, звёзды, настройки и последние обработанные заезды. Старый `smash-city-v1` читается и мигрирует без удаления; баланс и настройки первой части сохраняются. При повреждённом новом сохранении используется старое или безопасное начальное состояние. Бонус за один `runId` повторно не начисляется; 100 последних идентификаторов сохраняются для защиты от повторного экрана результата.

Новые/расширенные файлы: `content.js`, `progression.js`, `simulation.js`, `platform.js`, `art.js`, `scene.js`, `main.js`, `style.css` в `src/smash`, а также профильные тесты. Команды запуска остаются прежними.

## Проверки второй части

Прошли 48 модульных проверок и все 8 браузерных сценариев (включая регрессии первой части), установка из lockfile и production-сборка. В production отдельно проверены покупка экскаватора (1000→700), выбор, удар и получение 25 монет; ошибок JavaScript нет, тестовый интерфейс отсутствует.

Профильные тесты покрывают миграцию, покупки/недостаток монет, повторное начисление, открытие уровней, звёзды/рекорды, точный момент и направление урона, массовый удар, соседний урон цепи, лимит шести зданий и сброс отложенных воздействий. Непрерывные маршруты без телепортации и прямого изменения прочности подтверждают выполнимость всех четырёх миссий бульдозером. Это оптимальный тестовый навигатор, а не измерение времени обычного игрока.

После прогрева 40 переключений районов не увеличивают количество представлений (221) и текстур (186); пул частиц остаётся 100. Браузерные проверки используют реальные нажатия/касания и управляемый тактовый шаг для точной проверки удара. Подготовка профиля для отдельных сценариев явно отделена от игрового прохождения; физический смартфон по-прежнему не проверен.

## Для части 3

Платформенные SDK и жизненный цикл Яндекс Игр/CrazyGames, реальные рекламные интеграции, платформенные сохранения, полная локализация, финальная мобильная адаптация и подготовка публикации. ## Границы проверки

Модульные проверки не подменяют ручной баланс. Браузерные сценарии точного контакта используют управляемое время; сценарии целевых атак могут устанавливать стартовую позицию, но не прочность и урон зданий. Непрерывные миссии отдельно проходят без таких подмен. Стабильное количество объектов/текстур при переключениях — ограниченная проверка ресурсов, а не полный heap-профиль. Внешний вид проверен в Chromium при настольных и мобильных разрешениях; физический телефон и целевые 30/60 FPS на слабом оборудовании не подтверждены.

Декор остаётся проезжаемым; столкновения есть у целых зданий и границ карты. Башни падают по заранее заданному направлению +X, а не по физике. При отключённом localStorage доступны текущие заезды и покупки в памяти, но прогресс не переживёт закрытие страницы. История обработанных результатов ограничена 100 последними заездами; UI не восстанавливает старые экраны результата после перезагрузки.

Vite предупреждает о размере Phaser vendor-chunk (~1,48 МБ, ~340 КБ gzip); сборка проходит. Файлы старой игры в `src/game` не подключены к новой сборке. Пользовательская публикация, SDK, онлайн-сохранения и реклама не выполнялись.
