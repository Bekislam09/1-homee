# Smash City — архитектура

Vite + JavaScript ES Modules + Phaser 3. Проект отображает объёмные 2D-объекты; Three.js и 3D-физика в новой игре не используются.

## Модули
- `src/smash/simulation.js`: чистая 2D-симуляция, движение, коллизии, таран, здания, комбо, таймер и миссия.
- `src/smash/art.js`: процедурные локальные спрайты, проекция и городской декор.
- `src/smash/scene.js`: Phaser Scene, объекты города, сортировка по глубине, камера, эффекты и синхронизация с симуляцией.
- `src/smash/main.js`, `style.css`: меню, HUD, настройки и доступный ввод.
- `src/smash/i18n.js`: ключи игровых сообщений, русский fallback, задел для локализации.
- `src/smash/audio.js`: процедурные эффекты Web Audio.
- `src/smash/platform.js`: локальное сохранение и независимый интерфейс платформы.

## Координаты и данные
Симуляция использует плоские мировые координаты. Только рендер применяет `screenX=(x-y)*0.866`, `screenY=(x+y)*0.5`; вертикальная высота объектов вычитается из screenY. Клавиатурный и сенсорный ввод переводится обратно в мировые координаты. Глубина сортируется по x+y у основания объекта.

Состояние заезда хранит игрока, 14 зданий, время, очки, монеты и комбо. События попадания и разрушения запускают эффекты, но не начисляют награды: начисление выполняется ровно один раз внутри симуляции. Перезапуск создаёт свежий заезд, сохраняя кошелёк. Пул частиц ограничен; ресурсы города переиспользуются.

## Сцены и ресурсы
Одна игровая Phaser Scene показывает город как фон меню и как игровое поле. Состояния UI: меню, игра, пауза/настройки, результат. Все спрайты создаются локально при загрузке; звук разрешается первым действием пользователя. Будущие SDK подключаются через PlatformAdapter; реклама сейчас отсутствует.
